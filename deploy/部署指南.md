# 贤霖科技官网 · 云服务器部署指南

> 适用方案：**整站（前台网站 + 后台管理）部署到一台云服务器**，GitHub 仅作为代码仓库。
> 部署完成后：前台 `https://你的域名`，后台 `https://你的域名/admin.html`，24 小时在线，改内容实时生效。

---

## ⚠️ 第一步：先决定服务器放在哪个地域（决定要不要备案）

这是整个部署里**唯一会卡住进度**的事，请先定：

| | 中国大陆节点（深圳/杭州/北京等） | 中国香港 / 海外节点 |
|---|---|---|
| 是否要 ICP 备案 | **必须备案**，否则域名无法访问网站 | **免备案**，买到就能用 |
| 备案耗时 | 约 7–20 个工作日（免费，需营业执照等资料） | 无 |
| 国内访问速度 | 快（10–30ms） | 较快（30–80ms） |
| 适合场景 | 长期正式运营，不急于上线 | 想尽快上线、先跑起来 |

**备案要准备什么**（走大陆节点时）：营业执照、法人身份证、网站负责人身份证 + 手机号、域名证书（阿里云域名自动实名认证后可获取）。在阿里云控制台搜「备案」进入 ICP 备案系统在线提交，法人或负责人需用阿里云 App 做人脸核验。

**结论建议**：
- 能等两周、追求国内访问速度 → 大陆节点 + 备案（推荐长期方案）
- 想这两天就上线 → 先买香港节点做起来，域名随时能迁到大陆节点（迁移 = 重新解析 + 服务器上重新部署一次）

## 一、购买服务器

以**阿里云轻量应用服务器**为例（比 ECS 便宜且更适合单站点）：

1. 登录阿里云控制台 → 搜索「轻量应用服务器」→ 创建服务器
2. 地域：按上面决定（香港 / 深圳 等）
3. 镜像：**应用镜像 → Node.js**（省去装环境）；如果没有，选 **系统镜像 → Ubuntu 22.04**
4. 规格：**2 核 2G、40G 系统盘、3M 带宽**起步足够（日均几千 PV 完全够用）
5. 时长：建议直接买 1 年，比按月便宜很多
6. 创建后记下**公网 IP**（形如 `47.xx.xx.xx`）和 root 密码

**安全组 / 防火墙**要放通的端口：

| 端口 | 用途 | 必须 |
|---|---|---|
| 22 | SSH 远程登录 | ✅ |
| 80 | HTTP 网站访问 | ✅ |
| 443 | HTTPS 网站访问 | ✅ |
| 8080 | Node 服务端口 | ❌ 不用对外开（走 Nginx 转发，更安全） |

## 二、把网站上传到服务器

### 方式一：从 GitHub 克隆（推荐，后续更新方便）

私有仓库需要一个 GitHub Token（`repo` 权限）：

```bash
ssh root@你的服务器IP

mkdir -p /opt && cd /opt
git clone https://Qinglian168:<你的TOKEN>@github.com/Qinglian168/xianlin-website.git xianlin-website
cd xianlin-website
```

### 方式二：本地打包上传（不想用 Token 时）

在**你的 Mac** 上执行：

```bash
cd /Users/macbook/WorkBuddy/贤霖科技官网
tar --exclude='.git' --exclude='node_modules' --exclude='.workbuddy' \
    -czf /tmp/xianlin-website.tar.gz .
scp /tmp/xianlin-website.tar.gz root@你的服务器IP:/opt/

# 服务器上解压
ssh root@你的服务器IP
mkdir -p /opt/xianlin-website && tar -xzf /opt/xianlin-website.tar.gz -C /opt/xianlin-website
cd /opt/xianlin-website
```

## 三、一键部署

```bash
cd /opt/xianlin-website
bash deploy/deploy.sh
```

脚本会自动完成：装 Node.js 20 → 装 pm2 进程守护 → 建 `logs/`、`images/uploads/` 目录 → 初始化数据文件 → 启动服务并设置开机自启。

看到「部署完成」后本机验证：

```bash
curl -I http://127.0.0.1:8080     # 应返回 HTTP/1.1 200 OK
pm2 status                        # 应显示 xianlin-website online
```

**配置开机自启**（脚本最后一行会打印出确切命令，直接复制执行即可）：

```bash
sudo env PATH=$PATH:$(dirname $(command -v pm2)) pm2 startup systemd -u root --hp /root
```

## 四、安装 Nginx 反向代理

为什么需要它：让访问者用 `域名`（80/443）访问，Node 服务藏在 8080 后面；同时用于申请 HTTPS 证书。

```bash
# Ubuntu / Debian
sudo apt update && sudo apt install -y nginx

# Alibaba Cloud Linux / CentOS
sudo yum install -y nginx
```

复制配置文件并**替换成你的真实域名**：

```bash
sudo cp /opt/xianlin-website/deploy/nginx-xianlin.conf /etc/nginx/conf.d/xianlin.conf
sudo sed -i 's/xianlin\.com/你的域名/g' /etc/nginx/conf.d/xianlin.conf
sudo nginx -t && sudo systemctl enable nginx && sudo systemctl restart nginx
```

此时用浏览器访问 `http://服务器公网IP` 应该能看到网站首页（还没绑域名也能先用 IP 验证）。

## 五、域名解析（阿里云）

域名在阿里云注册的话，解析就在**云解析 DNS** 里做：

1. 登录阿里云控制台 → 搜索「**云解析 DNS**」→ 域名解析 → 找到你的域名 → 点「**解析设置**」
2. 点「**添加记录**」，按下表加两条（`@` 表示域名本身）：

| 记录类型 | 主机记录 | 解析线路 | 记录值 | TTL |
|---|---|---|---|---|
| A | `@` | 默认 | `你的服务器公网IP` | 10 分钟 |
| A | `www` | 默认 | `你的服务器公网IP` | 10 分钟 |

> 如果原来有 `@` 或 `www` 的记录（比如指向旧的虚机或托管平台），**先删掉再加**，同一主机记录不能有两条 A 记录指向不同 IP。

3. 保存后等 1–10 分钟生效，本机验证：

```bash
ping 你的域名            # 返回的 IP 应该是你的服务器 IP
nslookup www.你的域名    # 同样应指向服务器 IP
```

4. **备案要求**：如果服务器是大陆节点，域名必须先完成 ICP 备案，80/443 才能正常对外服务（未备案会被阿里云拦截并跳转提示页）。香港节点不需要备案。

## 六、开启 HTTPS（强烈建议，后台密码不能明文传输）

```bash
sudo apt install -y certbot python3-certbot-nginx     # CentOS 用 yum
sudo certbot --nginx -d 你的域名 -d www.你的域名
```

按提示填邮箱、同意条款，certbot 会自动改好 Nginx 配置并申请免费证书（90 天自动续期，无需手动操作）。

完成后访问 `https://你的域名` 应显示小锁图标，后台地址为 `https://你的域名/admin.html`。

## 七、上线后的安全加固（务必做）

1. **立刻改后台密码**
   打开 `https://你的域名/admin.html` 登录（初始密码 `admin123`）→ 修改密码。默认密码在公网上等于没有防护。

2. **限制后台访问来源**（可选，更安全）
   在 `/etc/nginx/conf.d/xianlin.conf` 里加一段，只允许你的办公/家庭 IP 打开后台：

   ```nginx
   location = /admin.html {
       allow 你的办公公网IP;
       deny all;
       proxy_pass http://127.0.0.1:8080;
       proxy_set_header Host $host;
   }
   ```
   注意：家里宽带 IP 会变，改完记得测试，别把自己锁在外面。

3. **定期备份数据**
   后台改动的产品/新闻存在服务器 `data/` 目录，上传的图片在 `images/uploads/`，这两个目录必须定期备份：

   ```bash
   # 在服务器上打包备份到本地
   tar -czf /root/xianlin-backup-$(date +%F).tar.gz -C /opt/xianlin-website data images/uploads
   ```
   建议把备份文件下载回自己电脑保存。

## 九、常见问题排查

| 现象 | 原因 / 解决 |
|---|---|
| 浏览器打不开，提示连接超时 | 安全组没放通 80 端口；或服务器上 Nginx 没启动（`sudo systemctl status nginx`） |
| 打开是阿里云备案提示页 | 大陆节点 + 域名未备案，去完成 ICP 备案，或换香港节点 |
| 显示 502 Bad Gateway | Node 服务挂了，执行 `pm2 status` 看状态、`pm2 logs xianlin-website` 看报错，然后 `pm2 restart xianlin-website` |
| 域名解析不生效 | 用 `ping 域名` 看是否指向服务器 IP；阿里云解析线路选「默认」；等待 TTL 过期（最多 10 分钟） |
| 后台能登录但保存失败 | 检查 `data/` 目录权限：`chmod -R u+rw /opt/xianlin-website/data` |
| 图片上传失败 | 检查 `images/uploads/` 权限；Nginx 里 `client_max_body_size` 是否够大（默认已设 20m） |
| 服务器重启后网站打不开 | pm2 开机自启没配置成功，重新执行第四节里的 `pm2 startup` 命令 |
