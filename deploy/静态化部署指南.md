# 贤霖科技官网 · 静态化部署指南

> **方案 A：纯静态化** — 不需要云服务器，不需要 ICP 备案，大陆访问速度快
> 适用：39 个产品展示、8 篇新闻、公司介绍、联系方式（前台功能 100% 保留）
> 失去的功能：后台管理 `admin.html`（已从 dist 移除）

## 一、本地预览（Mac 上立刻看效果）

```bash
cd /Users/macbook/WorkBuddy/贤霖科技官网/dist
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080` 即可看到完整网站。

> ⚠️ 注意：
> - 不要在 `dist/` 父目录跑（那样会去取源 HTML 看到的是空数据）
> - 预览服务器**必须**在 `dist/` 内启动，否则列表页 fetch 不到 `data/*.json`

## 二、改完内容后重新生成

当你或我在 Mac 上改了 `data/products.json` / `data/news.json` / 任意 `*.html` 文件后，跑一次构建：

```bash
cd /Users/macbook/WorkBuddy/贤霖科技官网
node build.js
```

**产物**：`dist/` 目录里的内容就是可以直接上传到任何静态托管服务的东西。

构建脚本做了什么：
- 读 `data/products.json` → 生成 `dist/products/{1..39}.html`（39 个独立产品详情页）
- 读 `data/news.json` → 生成 `dist/articles/{1..8}.html`（8 个独立新闻详情页）
- 复制通用页面（首页/about/contact/solutions/products/news）
- 修复所有链接：`product.html?id=N` → `products/N.html`
- 拷贝 `css/` `js/` `images/` `data/` 到 `dist/`

## 三、部署到国内 CDN（让别人能访问）

### 推荐方案：腾讯云 Webify

| 特性 | 说明 |
|---|---|
| 价格 | 免费额度（中小企业站永远够用） |
| 大陆速度 | 🚀 快（腾讯自家 CDN） |
| ICP 备案 | **免备案**：可用 `xxx.webify.app` 二级域名立即上线 |
| 自定义域名 | 支持，但需要 ICP 备案 |
| 部署方式 | 绑定 GitHub 私有仓库 → 推送即部署 |

**步骤（约 30 分钟完成）**：

1. 注册腾讯云账号（实名认证，几分钟）
2. 进入 [腾讯云 Webify 控制台](https://console.cloud.tencent.com/webify) → 新建项目 → 选择「从 Git 仓库导入」
3. 选择你的 GitHub 仓库 `Qinglian168/xianlin-website`（**私有**仓库可以直接绑定）
4. 构建设置：
   - 框架预设：**Other**
   - 构建命令：`node build.js`
   - 输出目录：`dist`
   - Node 版本：18 或更高
5. 点部署 → 30 秒后获得一个 `xxx.webify.app` 链接，立即可访问

**优点**：
- 后续更新只需 `git push`，Webify 自动检测推送、跑构建、部署上线（30 秒全网生效）
- **不需要买服务器、不需要备案、不需要管运维**

### 备选方案 A：腾讯云 COS 静态网站

适合"一次性上传文件、不绑定 Git"的场景：

1. 腾讯云控制台 → 对象存储 COS → 新建存储桶（**公有读私有写**、开启静态网站）
2. 上传 `dist/` 全部内容到存储桶根目录
3. 在「权限管理」里开启「静态网站托管」→ 获得 `xxx-1234567890.cos-website.ap-guangzhou.myqcloud.com` 访问链接
4. 想绑定自有域名？在「域名管理」添加 CDN 加速 + 自定义域名（要 ICP 备案）

### 备选方案 B：阿里云 OSS + CDN

类似腾讯云 COS，价格和功能几乎一样，按你账号在哪家方便选哪个。

### 备选方案 C：七牛云

- 七牛云是国内老牌静态托管，免费额度 10GB 流量/月
- 注册 → 对象存储 → 上传 `dist/` 全部文件 → 获得测试域名
- 自定义域名要 ICP 备案

### 不推荐方案

- **GitHub Pages**：大陆访问慢（200ms+），且不绑自定义域名时是 `xxx.github.io`
- **Vercel / Netlify**：海外平台，大陆访问慢
- **自购云服务器**：成本高、运维麻烦（除非后续需要后台功能）

## 四、绑定自有域名（可选，需要 ICP 备案）

如果你有自己的域名（比如 `xianlin-tech.com`），想让它指向这个静态站：

1. 在腾讯云/阿里云买域名（约 80 元/年）
2. **ICP 备案**：约 7-20 天，免费，需要营业执照
3. 在 Webify / COS 控制台添加自定义域名
4. 在域名解析 DNS 添加 CNAME 记录指向 Webify 提供的地址

## 六、关于"代码可见"

> **诚实说明**：HTML/CSS/JS 文件对所有访问者必然可见（这是 Web 工作原理：浏览器必须下载才能渲染）。
> 任何销售说"源代码不可见"的都是忽悠。

**已做到的客观保护**：
- ✅ GitHub 仓库**私有**：只有你自己看到源码（别人必须 fork 你才能看，且要 GitHub 通知你）
- ✅ `data/config.json`（后台密码）**不推送**（在 `.gitignore` 里排除）
- ✅ Webify 上的 `dist/` 目录只暴露渲染结果（已经是 minify 友好的 HTML）
- ⚠️ 如果产品图/文案需要严格保护 → 加水印 + 页脚 © 声明 + 不放商业敏感数据

## 七、文件清单

```
xianlin-website/
├── index.html ... solutions.html    # 源 HTML（含 JS 动态加载逻辑）
├── product.html                     # 产品详情模板（构建时用）
├── article.html                     # 新闻详情模板（构建时用）
├── data/
│   ├── products.json                # 39 个产品
│   └── news.json                    # 8 篇新闻
├── images/                          # 所有图片资源
├── css/  js/                        # 样式和脚本
├── build.js                         # ⭐ 构建脚本（核心）
└── dist/                            # ⭐ 构建产物（上传 CDN 的就是这个）
    ├── index.html ... solutions.html
    ├── products/{1..39}.html        # 独立产品页
    ├── articles/{1..8}.html         # 独立新闻页
    ├── css/  js/  images/
    └── data/{products,news}.json    # 列表页用的兜底数据
```

`admin.html` `server.js` `data/config.json` `data/stats.json` **不会被复制到 `dist/`**（已剔除后台相关）。
